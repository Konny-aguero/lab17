# Evidencias reales

Los archivos `antes.txt` son extractos identificados de registros originales o del código original preservado. Los `despues.txt` son salidas del verificador contra la aplicación corregida. `codigo_corregido.txt` muestra extractos numerados del parche. Los originales completos están en `docs/evidencias/`.

Los archivos `antes-navegador.txt` y `despues-navegador.txt` de XSS registran observaciones reales de Microsoft Edge automatizado. `flujo-normal-navegador.txt` registra el flujo funcional normal.

`validacion-maven.txt` y `validacion-angular.txt` contienen las salidas de compilación/pruebas. Los extractos `prueba-maven.txt` remiten al registro completo.

Las imágenes `antes.png`, `despues.png` y `codigo_corregido.png` están pendientes. No se han creado archivos de imagen vacíos ni capturas artificiales. Sigue `docs/GUIA_CAPTURAS.md` para obtenerlas.

`SHA256SUMS.txt` registra la huella de los textos de esta entrega. Si repites una prueba y reemplazas su archivo, el contenido y la huella cambiarán; conserva la versión anterior mediante Git para mantener el historial.
